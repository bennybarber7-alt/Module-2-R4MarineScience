# MB5370 Module 2: R for Marine Science

## Overview
R-based data wrangling, statistical analysis, and visualisation workflows for
marine ecological datasets, developed for MB5370 (Techniques in Marine Science 1).

## Background & Aims
This module builds on the foundational R skills from Module 1, applying them to
real ecological data. The focus is on the applied analytical skills marine
scientists need to organise, interpret, and visualise data.

## Structure
- `code/` — Analysis scripts for each workshop
- `data/` — Input datasets used across workshops
- `Outputs/` — Figures, tables, and rendered results
- `README.md`

## Dataset(s)
Data provided via my JCU professor's GitHub repository as part of the MB5370
workshop series. The `data/` folder contains estuarine and reef ecological
data (fish catch records, water quality readings, benthic cover surveys,
acoustic telemetry, and a species name lookup table) used across the module's
workshop exercises.

## Key Outputs
See `Outputs/` for generated plots, tables, and analysis results from each
workshop exercise.
