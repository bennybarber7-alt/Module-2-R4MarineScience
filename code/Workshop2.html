This workshop improved my confidence in cleaning and reorganising complex datasets in R. I learned that tidy data, consistent formatting and careful handling of missing values are essential for combining datasets correctly and producing reliable results.

Tidying data

How we make our dataset tidy is by following three interrelated rules. Each variable must have its own column. Each observation must have its own row. Each value must have its own cell.

adding the values_drop_na = TRUE argument to the pivot_longer() call drops all rows where the rank variable is NA. This is useful because we only want to keep rows where there is a rank value, and not rows where there is no rank value (NA).

mutate() and parse_number() are used to convert the week variable from a character variable (e.g. “wk1”) to a numeric variable (e.g. 1). This is done by first using parse_number() to extract the numeric part of the week variable, and then using mutate() to create a new variable called week_num that contains the numeric values.

billboard_longer <- billboard |> 
  pivot_longer(
    cols = starts_with("wk"), 
    names_to = "week", 
    values_to = "rank",
    values_drop_na = TRUE
  ) |> 
  mutate(
    week = parse_number(week)
  )

Wrangling strings and dates

Standardising text with stringr

library(tidyverse)

# A remarkably messy data frame of field sites
messy_sites <- tibble(
  site_id = c(" Nelly Bay", "nelly_bay", "NELLY BAY", " Geoffrey_Bay ", "geoffrey bay")
)

# Using stringr within mutate to standardize the text
clean_sites <- messy_sites |>
  mutate(
    # 1. Convert everything to lowercase
    site_clean = str_to_lower(site_id),
     # 2. Trim any leading or trailing whitespace (invisible spaces at the ends)
    site_clean = str_trim(site_clean),
    # 3. Replace any spaces with underscores
    site_clean = str_replace_all(site_clean, pattern = " ", replacement = "_"),
   
  )

print(clean_sites)

Mastering time with lubridate

library(lubridate)

# Parsing different date formats
date_1 <- dmy("25/12/2026")
date_2 <- ymd("2026-12-25")

# R now recognizes these as identical Date objects
date_1 == date_2
[1] TRUE

If your dataset contains a date formatted as “25/12/2026”, the day comes first, then the month, then the year. Therefore, you use the dmy() function. If the date is “2026-12-25”, you use ymd().

For high-frequency marine data, such as acoustic telemetry or CTD profiles, we often need to parse exact timestamps. We do this by appending _hms (hours, minutes, seconds) to our functions.:

# A tibble of raw sensor data with a messy character timestamp
sensor_data <- tibble(
  raw_time = c("14-05-2026 08:30:00", "14-05-2026 08:45:00", "14-05-2026 09:00:00"),
  temperature = c(24.5, 24.6, 24.4)
)

# Converting character strings to true POSIXct datetime objects
sensor_clean <- sensor_data |>
  mutate(
    true_time = dmy_hms(raw_time)
  )

print(sensor_clean)
